# 📊 Power BI Satış Analizi Dashboard

## 🎯 Amaç
Bu projede satış verileri analiz edilerek iş kararlarını destekleyecek bir dashboard hazırlanmıştır.

## 🛠 Kullanılan Araçlar
- Power BI
- DAX
- Veri modelleme

## 📈 Dashboard İçeriği
- Toplam satış
- Aylık satış trendleri
- En çok satan ürünler
- Bölgesel analiz

## 🔍 İçgörüler
- En yüksek satış belirli aylarda yoğunlaşmıştır
- Belirli ürünler satışın büyük kısmını oluşturmaktadır

## 📌 Kullanım
.pbix dosyasını indirerek Power BI ile açabilirsiniz.
